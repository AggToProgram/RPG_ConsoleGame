This is my first ever java project in which I use JDBC. It's a console-based simple RPG game that is played out in Dorava's Dungeon, a small dungeon with 6 rooms, each with a bit of a symbolic touch... 

It includes 4 monsters (one of them is a boss) that allow you to gain exp and level up by fighting them. It also has 4 available items that allow you to buff your stats and be the most POWERFUL.

It is still a WIP and I will try to finish up a few more updates until I can consider this project finished.
